## About
This is a fictional student dataset I created for data mining practice. The records are made up and do not describe real students.

## Files
- `students.csv` - the dataset (30 records, 5 columns)
- `student_dataset.py` - Python script that generates the data

## Columns
| Column | Type | Description |
|---|---|---|
| Student ID | text | Unique ID (STU001 to STU030) |
| Department | text | Computer Science, Cyber Security, Software Engineering, Data Science or Information Technology |
| Level | number | Year level: 100, 200, 300 or 400 |
| Attendance Percentage | number | Attendance from 50 to 100 |
| Average Exam Score | number | Average exam score from 35 to 95 |

## How to run
Run `python student_dataset.py` to create `students.csv`. The values are random, so each run gives different numbers.
